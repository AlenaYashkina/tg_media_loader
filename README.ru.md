# Telegram Media Loader — выгрузка и организация медиаданных

[English README](README.md) · [Скриншот интерфейса](docs/screenshots/gui-dashboard.png)

**Задача.** Выгрузить фотографии и другие вложения из Telegram без повторной загрузки, сохранить структуру каналов, тем и альбомов и передать результат в последующие этапы фотоотчётности.

**Решение.** Python/Telethon с CLI и Tkinter GUI. Вложения сохраняются по каналу, теме, дате сообщения и альбому; SQLite-реестр хранит уже обработанные сообщения, а NDJSON — метаданные.

**Мой вклад.** Проектирование назначения и структуры выгрузки, последовательности операций и интерфейса, интеграция в процесс подготовки отчётов и проверка с AI coding assistants.

**Офлайн-проверка без Telegram.** `python -m pip install -e .`; `python examples/offline_layout_demo.py`. Скрипт использует вымышленные ID и текстовые заглушки, проверяет группировку альбома, границу суток UTC и отсутствие дублей при повторе. Результат подтверждён GitHub Actions.

**Ограничения.** Дата каталога — дата сообщения в Telegram, а не обязательно съёмки. Настоящие сообщения могут включать персональные данные, поэтому реальные выгрузки не предназначены для публичного репозитория. Для офлайн-демо не нужны Telegram-ключи.
